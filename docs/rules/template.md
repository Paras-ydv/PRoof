# PR template

The repository has a pull request template, and PRoof checks that each section has real content.

## How to fix it

Edit your PR description and fill in every section under the template's headings. A sentence or two is usually enough. If a checklist applies, tick the boxes that are true.

Leaving the template's placeholder text in place counts as empty. If a section really doesn't apply, write "Not applicable" and say why in a few words.
