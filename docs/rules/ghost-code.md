# Ghost code

PRoof found a function, method or import in your added lines that isn't defined anywhere in the repository. This often happens when code is generated by an AI tool that guesses at an API.

## How to fix it

1. Open the file and line linked in the report.
2. Check whether the name exists. Search the repository, and the library's documentation if it's an import.
3. Either use the function that really exists, or add the missing function in this PR.

PRoof only flags names it can prove are missing: calls on objects whose type it can't know are never flagged. If you believe this flag is wrong, say so on the PR. Maintainers can mark it as a false flag, which helps tune the check.
