# Spray pattern

This is shown only to maintainers, never on the PR, and it never changes the score.

It lists recent pull requests the author opened in unrelated repositories within a short window. Many PRs across many unrelated projects can mean low-effort or automated contributions, but active open-source contributors also open many PRs. Use it as context, and look at the PR itself.

The data comes from GitHub's public events feed, which can lag by up to a few hours.
